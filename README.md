# deepseek-harness-skin | OpenClaw
A dual-platform theme skin pack + desktop pet asset system for DeepSeek-Harness & WorkBuddy.

一包两应：同时适配 DeepSeek-Harness、WorkBuddy。
内置14套美化主题，支持GIF动态壁纸、自定义配色、插件跨联动，原生内置版本检测更新弹窗；
集成 OpenClaw 桌面宠物能力，支持透明PNG帧动画桌宠，可一键召唤。

## Features
- ✅ Static / GIF wallpaper support（静态/GIF动态壁纸）
- ✅ Custom color theme（自定义配色主题）
- ✅ Cross-plugin linkage（插件跨联动）
- ✅ Built-in auto version check & update popup（原生版本检测+更新弹窗）
- ✅ Built-in OpenClaw transparent frame-animation desktop pet（内置OpenClaw透明帧动画桌面宠物）

## Quick Install
1. Download release package
2. Load in DeepSeek-Harness / WorkBuddy skill manager
3. Support command: summon / close desktop pet
